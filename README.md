# Casual Mobile Game

A simple tap-based mobile game built with React Native and Expo.

## Game Description
- Tap the red targets that appear on the screen to score points
- Each target is worth 10 points
- Game duration: 30 seconds
- Try to get the highest score possible!

## Installation

1. Make sure you have Node.js installed on your computer
2. Install Expo CLI globally:
```bash
npm install -g expo-cli
```

3. Install project dependencies:
```bash
npm install
```

## Running the Game

1. Start the development server:
```bash
npm start
```

2. Use the Expo Go app on your mobile device to scan the QR code, or run on an emulator:
- Press 'a' to run on Android emulator
- Press 'i' to run on iOS simulator
- Press 'w' to run in web browser

## Controls
- Simply tap on the red targets that appear on the screen
- The game automatically ends after 30 seconds
- Press "Play Again" to restart the game

## Features
- Simple and intuitive gameplay
- Score tracking
- Timer countdown
- Responsive design for different screen sizes
- Smooth animations
